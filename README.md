# Warehouse Acceptance & Barcode Management System (v2.0)

Современная легковесная веб-система складского учета, адаптированная под **терминалы сбора данных (ТСД)**, смартфоны и ПК. 
Полностью автономна, работает с базой **SQLite** и разворачивается в **Portainer** в один клик.

---

## 🚀 Основные возможности

1. **Гарантия сохранности данных (Zero-Loss / Local-First):**
   - Сканирование обрабатывается **мгновенно (0 мс)** в памяти устройства со звуком и виброоткликом.
   - Все пики сохраняются в локальную очередь (`Sync Queue`).
   - При кратковременном обрыве Wi-Fi работа **не прерывается**: очередь накапливается на устройстве и автоматически досылается на сервер при восстановлении связи.

2. **Эргономика для ТСД и смартфонов:**
   - Камера и QuaggaJS убраны (система стала в 3 раза легче и быстрее).
   - **Режим ТСД:** блокирует всплытие экранной клавиатуры Android (`inputmode="none"`), освобождая 100% экрана под товары.
   - Автофокус никогда не теряется из поля сканирования.
   - Компактный карточный интерфейс (без горизонтальной прокрутки на маленьких экранах).
   - Цветовая индикация (зеленый — принято ровно, желтый — в процессе, красный — излишек/ошибка).
   - Автоскролл к последней отсканированной позиции.

3. **База данных SQLite вместо Excel-файлов:**
   - Высокая скорость, транзакции, нет риска повреждения файла.
   - **Множественные штрихкоды:** у одной позиции может быть сколько угодно штрихкодов минибоксов и упаковок с разными кратностями.
   - **Синхронизация через Excel (Round-Trip):** в любой момент можно выгрузить базу в `.xlsx`, отредактировать на компьютере и залить обратно (режим объединения Merge).

4. **Управление упаковочными листами прямо через веб:**
   - Загрузка листов поставщиков (`.xlsx`, `.xls`, `.csv`).
   - Статусы: **Новый** ➔ **В процессе** ➔ **Принят**.
   - Функция **«Перепринять»** (обнуление счетчиков и повторная приёмка).
   - Выгрузка **Акта расхождений в Excel** (сравнение заявленного и фактического количества).
   - Удаление старых листов.

## 🛠 Развертывание в Portainer

### Способ 1: Через Git-репозиторий (Рекомендуемый)
1. Создайте репозиторий на GitHub (например, `warehouse-app`).
2. В терминале в папке `warehouse-portainer`:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/warehouse-app.git
   git push -u origin main
   ```
3. В Portainer:
   - Перейдите в **Stacks** ➔ **Add stack**.
   - Выберите метод **Repository**.
   - Укажите URL вашего репозитория, ветку `main` и путь к файлу `docker-compose.yml`.
   - Нажмите **Deploy the stack**.

### Способ 2: Через Web Editor в Portainer
1. В Portainer перейдите в **Stacks** ➔ **Add stack** ➔ **Web editor**.
2. Вставьте содержимое файла `docker-compose.yml`:
   ```yaml
   services:
     warehouse-v2:
       build:
         context: https://github.com/ВАШ_АККАУНТ/warehouse-app.git#main
         dockerfile: Dockerfile
       container_name: warehouse-v2
       restart: unless-stopped
       ports:
         - "8070:80"
       volumes:
         - warehouse_data_v2:/var/warehouse_data
       environment:
         - APACHE_RUN_USER=www-data
         - APACHE_RUN_GROUP=www-data
         - DATA_PATH=/var/warehouse_data

   volumes:
     warehouse_data_v2:
       name: warehouse_storage_v2
   ```
3. Нажмите **Deploy the stack**.

## 🌐 Использование системы

После запуска перейдите в браузере (или браузере ТСД):
```text
http://IP_СЕРВЕРА:8070
```

1. **Загрузка базы товаров:**
   - Откройте вкладку **«База ШК»** ➔ нажмите **«Залить Excel (Merge)»** и выберите ваш файл `barcodeDB.xlsx`.
2. **Приёмка поставки:**
   - Откройте вкладку **«Листы»** ➔ **«+ Загрузить Excel»** и загрузите упаковочный лист поставщика.
   - Нажмите **«Принять»** ➔ откроется экран сканирования.
   - Сканируйте штрихкоды аппаратным сканером ТСД.
   - По завершении нажмите **«Завершить приёмку листа»**.
   - Во вкладке **«Листы»** можно скачать **Акт расхождений в Excel** или при необходимости нажать **«Перепринять»**.
